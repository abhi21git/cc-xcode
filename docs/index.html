cc-xcode

Xcode inside Claude Code. Build, run, test, preview and tap the simulator from one side panel, next to your prompt.

Install View on GitHub

One panel, five tabs.

It picks up Claude's own Xcode tool calls too. When Claude builds, runs tests, launches the app or renders a preview, the result appears in the panel.

Build

Live progress, then errors and warnings. Click a file to open that line in Xcode. Fix with Claude sends the issues to Claude.

Run

Build and run on the destination, with the app's stdout and OSLog streaming in.

Tests

Grouped by target and suite, failures first with their messages. Click a test to run only it, or rerun the failures.

Preview

Search the project's #Preview files and render one. Re-renders after Claude edits a previewed file.

Simulator

The booted simulator, about one frame a second. Click to tap, drag to swipe, type to send text.

Band

Scheme and destination pills above the prompt, the last result, and counters that open the matching tab.

Commands

Everything in the panel is also a slash command.

/xcodeOpen the panel
/buildBuild the active scheme
/runBuild and run on the active destination, then stream the console
/stopStop the running app
/tests [filter]Run all tests, or those whose Target/identifier contains the filter
/preview @file.swiftRender a #Preview. Without an argument: ContentView.swift, or the first file with #Preview

Install

Needs Xcode 27 or later, and Claude Code 2.1.293 or later in a terminal with the kitty graphics protocol, such as Ghostty.

1 · Xcode's MCP server
sudo xcrun mcp-server enable
claude mcp add --scope user xcode -- xcrun mcpbridge
2 · Allow it in ~/.claude/settings.json
{ "permissions": { "allow": ["mcp__xcode"] } }
3 · Install the mod
/plugin marketplace add abhi21git/cc-xcode
/plugin install cc-xcode@cc-xcode
Update
/plugin marketplace update cc-xcode
/plugin update cc-xcode@cc-xcode

Choose the user scope, then open Claude Code in a folder with an .xcodeproj or .xcworkspace. In other folders the mod stays hidden. Mods are an early-access Claude Code feature, so their API can change between releases.
